<!-- ─── PROJECT 3: Multi-Modal RAG System ────────────────────────────────────── -->

### <img src="https://img.shields.io/badge/03-Multi--Modal%20RAG%20System-0f172a?style=flat-square&logo=images&logoColor=818cf8" height="28"/>

<table>
  <tr>
    <td width="60%" valign="top">

**A fully local multi-modal RAG system that answers geography questions by searching through text and images from NCERT textbooks — no internet or API keys required.**

**Key Features:**
- **CLIP model** embeddings for unified text-and-image vector search space
- **ChromaDB** vector store with optimized chunking and dimension alignment
- Text-to-image retrieval — query with text, retrieve relevant textbook diagrams
- Complete offline operation with local model inference
- Cross-platform PDF rendering with Windows compatibility fixes

**Tech Stack:** `CLIP` `ChromaDB` `Python` `PDF Processing` `Vector Search`

**Challenges Solved:** Fixed **ChromaDB dimension mismatch** by enforcing consistent embedding shapes. Resolved **PDF rendering crashes on Windows** through cross-platform library configuration. Improved answer quality by implementing intelligent chunk sizing to prevent context overflow.
